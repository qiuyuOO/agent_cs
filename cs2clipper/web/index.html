    运行详情

    这个界面是什么

    给 cs2clipper 加的一层本地 Web 界面：选一首歌 + 一场 CS2 demo，自动分析音乐情绪、抽取 demo 亮点，编排剪辑点，渲染 2D 雷达画面，最后按音乐时长拼成片。

    • 不做游戏录屏：画面是 awpy 解析出的逐 tick 坐标画成的 2D 雷达，全自动、不需要开游戏。
    • 确定性打分 + LLM 只做决策：亮点评分是纯规则（可复现），LLM 只在“哪些素材、怎么排”这一层给建议，失败自动回落确定性编排。
    • 偏好会累积：显式设置、对话里说过的取向、历次出片参数都会作为证据进入偏好与画像。
